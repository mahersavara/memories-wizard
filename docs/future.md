# 🚀 Future Roadmap & Wishlist

This document tracks planned features, improvements, and community requests for the **Memories Wizard**.

## 📋 Feature Wishlist

### 1. Play / Pause Button for Videos
- **Description:** Add a dedicated toggle button to the video control bar to pause and resume playback manually.
- **Priority:** High
- **Estimate:** ~1 hour
- **Status:** Planned

### 2. Media Rotation Toggle
- **Description:** A checkbox or button to rotate the current image or video by 90-degree increments.
- **Estimate:** 
    - **UI Only (Preview Rotation):** ~2 hours. (Simple LayoutTransform in WPF / rotationEffect in SwiftUI).
    - **Persistent (Save to File):** ~6-10 hours. (Requires FFmpeg integration for videos and metadata/EXIF libraries for images).
- **Status:** Under Consideration

### 3. Native macOS Packaging (.dmg)
- **Description:** Automate the creation of DMG installers using GitHub Actions.
- **Estimate:** ~4 hours
- **Status:** Planned

### 4. Multi-Select / Batch Actions
- **Description:** Ability to select multiple files in a grid view and move/trash them all at once.
- **Estimate:** ~12-16 hours
- **Status:** Brainstorming

---
*Note: Estimates are approximate and based on current architecture.*
