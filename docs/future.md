# 🌟 Future Roadmap & Wishlist

This document tracks planned features and improvements for **Memories Wizard**.

## 🚀 Upcoming Features

### 1. Media Rotation Support
- **Description:** Add a button or checkbox to rotate images and videos by 90/180/270 degrees during the preview/sorting phase.
- **Estimation:** 
    - **UI:** Low (1-2 hours) - Adding the button and binding logic.
    - **Logic (Images):** Low (2-4 hours) - WPF supports easy `TransformedBitmap` for UI rotation. Permanent file rotation requires `BitmapEncoder`.
    - **Logic (Videos):** High (1-2 days) - Rotating video files permanently usually requires a library like **FFmpeg**. UI-only rotation in `MediaElement` is medium complexity using `LayoutTransform`.
- **Status:** 💡 Wishlist

### 2. Manual Play/Pause Control
- **Description:** Add a dedicated Play/Pause toggle button to the video control bar (currently videos autoplay on loop).
- **Estimation:** Low (1 hour) - Simple state toggle for the `MediaElement` engine.
- **Status:** 💡 Wishlist

### 3. Faded & Scale-down Swipe Exit
- **Description:** Enhance the Tinder-style swipe animation so that cards simultaneously **fade out** (opacity) and **shrink** (scale down) as they are being swiped away.
- **Estimation:** Low (2-3 hours) - Requires adding `ScaleTransform` and `Opacity` animations to the existing fly-off Storyboard in WPF and SwiftUI.
- **Status:** 💡 Wishlist
